Политика конфиденциальности Sliv116

  • Sliv116 получает доступ к Google Диску владельца только для синхронизации одной папки с сервером медиацентра.
  • Файлы передаются напрямую между сервером медиацентра и Google Диском. Никаким третьим лицам данные не передаются, не продаются и не используются для рекламы или аналитики.
  • Ключ доступа хранится только на сервере медиацентра, доступ к нему есть только у администраторов.
  • Доступ можно отозвать в любой момент: myaccount.google.com/permissions.

Privacy policy (English)

  • Sliv116 accesses the owner's Google Drive only to sync one folder with the media centre's server.
  • Files go directly between that server and Google Drive. No data is shared with third parties, sold, or used for advertising or analytics.
  • The access token is stored only on the media centre's server and is available only to its administrators.
  • Access can be revoked at any time at myaccount.google.com/permissions.
